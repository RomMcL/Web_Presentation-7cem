# Цементный калькулятор · Веб-презентация

Интерактивная веб-презентация для демонстрации возможностей методики «Регламент Иванова» по управлению себестоимостью цемента.

---

## 📌 О проекте

Проект представляет собой веб-слайдер с тезисным контентом, который может использоваться как самостоятельная презентация или как часть более крупного сайта (в перспективе).

**Почему слайдер, а не лендинг?**  
Контент взят из имеющейся PDF-презентации, соответственно, он тезисный и логически разбит на смысловые блоки. В формате слайдера это смотрится естественно и структурированно. Лендинг в данном случае выглядел бы недосказано и пустовато.

**Почему ваниль?**
Проект реализован как временное решение, основной целью которого является допуск заинтересованных лиц (по коду) к MVP основного продукта.

---

## 🎨 Цветовые схемы

В проекте реализовано несколько цветовых тем, доступных через кнопку переключения в правой части футера:

| Тема | Описание |
|------|----------|
| **Pure** | Чистые цвета (черный #000, белый #FFF) — максимальный контраст |
| **Soft** | Мягкие оттенки (по умолчанию) — сниженная нагрузка на зрение |
| **Forest** | Лесная гамма с зелеными оттенками |
| **Orange** | Теплая янтарно-терракотовая гамма |

Все темы используют приглушенные оттенки для комфортного восприятия, в отличие от исходного PDF-макета с чистыми цветами.

Выбор схемы сохраняется в localStorage.

## 🎮 Управление презентацией

### Режимы просмотра

**Ручной режим** (по умолчанию)
- Переключение слайдов: кнопки в шапке (◀ / ▶)
- Клавиши клавиатуры: ← / →
- Навигация по точкам в футере (с подсказками названий слайдов)
- Свайп (тач-устройства) — листание пальцем

**Авто режим**
- Запускается кнопкой «▶ Авто презентация»
- Автоматически пролистывает все слайды один раз и останавливается на первом
- Любое ручное управление (клавиши, свайп, нажатие на точку) отключает авторежим

> 💡 Ручной режим — циклический. Авторежим — однократный.

## ⏱️ Тайминги и анимации

- Длительность показа каждого слайда в авторежиме **настраивается индивидуально** (задаётся в массиве slides)
- Внутри слайда анимации элементов имеют собственную временную шкалу
- Анимации всех слайдов реализованы на CSS (keyframes)

**Перспективное развитие**  
При интеграции в полноценный сайт можно добавить звуковое сопровождение — голосовую дорожку для каждого слайда, синхронизированную с анимациями. Тайминги слайда тогда будут определяться длительностью аудио, что создаст эффект живого выступления спикера.

## 📧 Формы обратной связи

В проекте реализованы две модальные формы (доступны с первого слайда):

### 1. Демо-доступ (ввод кода)
- Поле ввода кода доступа
- Переход к калькулятору после успешной авторизации
- **Служебная возможность:** иконка замка в шапке ведёт в админ-панель для смены валидного кода

### 2. Запрос кода доступа
- Форма отправки письма (email)
- Поля: имя, почта, компания, телефон, комментарий
- Валидация обязательных полей (имя, почта, комментарий)
- Отображение статуса отправки (лоадер, успех, ошибка)

Формы не активны (на релизе будут взаимодействовать с бэкендом на Express).

Для работы отправки писем требуется настройка почтового клиента (здесь реализована имитация отправки письма).

## 🛠️ Технологии

| Технология | Назначение |
|------------|------------|
| **HTML5** | Семантическая разметка |
| **CSS3** | Анимации, гриды, флексбоксы, адаптивная верстка, CSS-переменные для тем |
| **JavaScript (ванильный)** | Логика слайдера, загрузка контента, управление режимами, валидация форм, свайп-события |
| **DOMPurify** | Санитизация загружаемого HTML-контента слайдов |

### Структура проекта
```bash
project/
├── index.html          # главная страница
├── css/
│   ├── main.css        # общие стили, шрифты, переменные
│   ├── index.css       # стили header/footer/модалок
│   └── slides.css      # стили отдельных слайдов
├── js/
│   └── index.js        # основная логика
└── slides/             # HTML-файлы слайдов
    ├── slide_first.html
    ├── slide_presContent.html
    └── ...
```
